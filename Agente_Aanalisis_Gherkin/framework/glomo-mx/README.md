#  REPO INFO
Front Cells (LitElement) project based on Web Components with E2E for mobile banking  
* Branching model:”scaled-tbd”
* Owner:"BBVA_MX_GLOMO_CHANNEL"
* Work model: 
    * *Develop*: The stable development branch. Release branches are created from this branch.
	* *Release*: Publish branch.  Each integration generates a new version of the binaries that will be automatically deployed..
	* *Feature*: Branches for the development of new features. They must follow the naming convention: feature/<jira_id><branch-name>. Jira code must belong to a GLOMO project. These branches can only be merged into develop.
	* *Bugfix*: Branch used for fixing bugs in the application before it has been released to clients. They must follow the naming convention: bugfix/<jira_id><branch-name>. Jira code must belong to a GLOMO project. 
	* *Hotfix*: Branch used for fixing bugs in the production application. They must follow the naming convention: hotfix/<jira_id><branch-name>. Jira code must belong to a GLOMO project.
